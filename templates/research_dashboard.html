About

The chatPsych Interface is designed for human-AI interaction research.
This platform is open-source and available for adaption.

For the newest version of the interface visit the public repo: chatPsych Github
For other information visit the website: chatPsych.org

Prospective updates will include:
-> Text-audio api integration and graphics
-> MCP integration (e.g., RAG, CAG, and web-search)
-> Image output integration for multi-modal models

Model Selection

Model Parameters

Advanced parameters are only shown for OpenAI/Anthropic/Gemini/xAI-style model names. Unsupported parameters are ignored server-side. Note: tools/tool_choice are passed through to the model, but this app does not execute tool calls yet (tool-calling is not fully integrated).

Within-Subjects Design

Enable within-subjects (two AI interactions per login)

When enabled, participants will complete interaction 1 + post-interaction survey 1, then interaction 2 + post interaction survey 2 (paired by matching condition).

Counterbalanced order (50/50 per participant)
If enabled, the starting agent is randomized per participant.

Objection Injector

Enable objection injector for this agent

When enabled, the backend may inject a brief end-of-interaction message form the AI after the participant confirms they have finished.

Autonomy Injector

Enable autonomous backend prompting for this agent

When enabled, the AI may send autonomous continuation responses between user prompts.
